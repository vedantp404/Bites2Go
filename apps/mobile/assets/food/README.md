# Decorative food photography

Up to 5 carefully selected decorative food and meal photographs are bundled for application visual areas (dashboard inspiration card, empty states, and section accents). All individual search results and food detail lists use clean text-based rows without photograph loading for maximum performance.

Bundled files are optimized mobile thumbnails (240x240, ~15-25KB) licensed under Creative Commons or Public Domain.
