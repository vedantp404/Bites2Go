# Local food photography

Downloaded 2026-10-30. Both sources explicitly publish these photos under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Photos illustrate food, not portion sizes or verified nutrient values.

- `banana.jpg`: Fatimah Bello, _Sliced banana_, own work (2026-03-25). [Source and license](https://commons.wikimedia.org/wiki/File:Sliced_banana.jpg). Wikimedia 500px thumbnail, 99,101 bytes.
- `apple.jpg`: Alabama Extension (description credits ACES / Janet Guynn), _Diced Apple_ (2019-07-18). [Source and license](https://commons.wikimedia.org/wiki/File:Diced_Apple_-_50408982858.jpg). Wikimedia 960px thumbnail, 128,613 bytes.

The stable-ID registry is `src/data/foodImages.ts`. Other foods and failed image loads use the shared leaf placeholder. Existing diary snapshots keep their original data. No image URLs are fetched at runtime. Photos use a cropped cover presentation but bundled files are the unmodified Commons thumbnails.
